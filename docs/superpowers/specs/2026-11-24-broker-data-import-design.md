# 券商数据转入股票大 Tab 设计

日期：2026-11-24
状态：已获陛下批准
范围：股票模块（持仓/交易/资本/净值），不触碰资产模块

## 一、意图与背景

把券商 APP 的最终持仓截图与 2026-01-08～2026-11-16 的 6 份资金流水，转换为 ETF-Solo 股票大 Tab 的数据：

- 5 只最终持仓（代码、数量、券商成本价）
- 55 笔真实买卖 → `solo_transactions` + 对应 trade 资金流水
- 银证转账、红利、利息、红利税 → `solo_capital_log`
- 以 2026-01-05 为净值基准日，补 4 笔期初建仓，使当日净值 = 1.0000

## 二、目标 / 非目标

| 类型 | 内容 |
|---|---|
| 目标 | 持仓、交易记录、资本流水、趋势/净值全部有数据；期末可用资金与券商一致 36,408.03；期末 5 只持仓成本与券商一致 |
| 非目标 | 不追求 2026 年以前的真实成本/交易；不修改资产模块；不写入 mqdx 项目 |
| 反目标 | 两套账本互相污染；把期初补建当成真实历史成交而不标注 |

## 三、已确认决策

| # | 决策 | 结论 |
|---|---|---|
| 1 | 净值基准日 | **2026-01-05**（2026 第一个交易日，1/1 休市） |

| 3 | 卖出成本 | 券商摊薄成本：`新成本 = (当前成本总额 − 卖出净到账) / 剩余股数`，用当前持仓成本，不再从全部流水重算 |
| 4 | 费率 | 以近 3 个月流水为准：佣金约 **1.5846‰**；印花税 0.5‰（仅股票卖出）；沪市过户费 0.01‰（买卖双向）；最低 5 元；ETF 卖出不收印花税 |

| 券商流水 | 写入 | 说明 |

## 六、净值口径

- 1/5：现金 44,864.55 + 市值 48,091 = 92,955.55；累计投入 92,955.55 → 净值 1.0000。
- 3/3～3/17：银证往返使累计投入临时降至 23,955.55，3/17 恢复 92,955.55；因现金同步减少/增加，净值不跳变。
- 6/9：+50,000，累计投入 142,955.55。
- 今日净值 = 119,981.03 / 142,955.55 = 0.8393。

## 七、卖出成本算法

券商成本价与流水核对：

- 百邦科技：`(买入总额 − 卖出净额) / 剩余 100 股 = 64.789`，与截图一致。
- 特变电工：流水重算 27.2465，减去红利 468/900 = 26.726，与截图一致。
- 立讯精密：流水重算 55.1873，减去红利 43.96/400 = 55.077，与截图一致。

因此券商采用“摊薄成本”：卖出后剩余成本 = (原成本总额 − 卖出净到账) / 剩余股数；红利会冲减成本。App 改为以**当前持仓成本**为起点计算，不再依赖全部历史流水，这样导入后未来卖出与券商一致。

## 八、费率模型（近 3 个月）

| 项目 | 费率 | 适用范围 |
|---|---:|---|
| 佣金 | 1.5846‰ | 全部买卖 |
| 印花税 | 0.5‰ | 股票卖出（ETF/基金卖出不收） |
| 过户费 | 0.01‰ | 沪市代码 5/6/9 开头，买卖双向 |
| 最低费用 | 5 元 | 全部 |

近 3 个月样例：中恒电气买 15,600 → 24.72；特变电工买 9,540 → 15.22；东方财富卖 18,000 → 37.53；特变电工卖 11,382 → 23.83；标普500 卖 5,420 → 8.67。允许 1～2 分钱的券商取整差异；历史流水按实际费用写入，不受估算影响。

## 九、边界与风险

| 风险 | 对策 |
|---|---|
| 期初 4 只为倒推，非真实历史成本 | 明确标注“期初建仓”；净值以 1/5 为 1；不影响期末持仓 |
| 编辑/删除历史交易会按流水重算成本 | 正常卖出已改用当前持仓成本；编辑历史属人工修正，需再与券商核对 |
| 2026 年前无流水 | 不追述；以 1/5 为起点 |
| 费率取整差异 | 历史用实际值；新交易允许 1～2 分钱差异 |
| 0 值快照污染净值 | 导入时删除 `pos_snap:2026-11-24` 0 值快照 |
| 交易记录只取 50 条 | 改为 200 条，确保 59 笔全部可见 |
